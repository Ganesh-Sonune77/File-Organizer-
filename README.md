# File Organizer (Python)

This is a simple Python script that organizes files in a folder based on their file type.  
It automatically sorts files into folders like Images, Videos, Documents, Music, etc.

## Features
- Automatically detects file types
- Creates folders for each category
- Moves files into respective folders
